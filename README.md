# QGis-Plugin LayerLib #

QGis-Python-Plugin to
- build a "Layer-Library" by storing metadata for "map-container-files" (*.qgz, *.qgs, *.qlr)
- registered map-container-files are displayed as TreeView in user defined folder-structure
- the layers in registered map-container-files can be added with all settings to current project


## Addendum ##
- The plugin has been developed under the latest versions since 2026, currently
  - QGIS 3.44 'Solothurn'
  - QGIS 4.2 'Belém do Pará'
  - Windows (10 + 11)
  - Linux (Ubuntu/Mint 22.3)
- not tested with older QGis-3-Versions and macOS
- please report bugs or ideas for missing features
